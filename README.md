# MazeWorld

MazeWorld is a 2D overhead RPG where you play as an adventurer navigating procedurally generated mazes. Explore environments, talk to NPCs, collect items, manage survival stats, and find your way out.

The project is both a **game builder** and a **game runtime**. Running `main.py` pre-generates all game content (mazes, NPCs, quests, items, portraits) and packages a standalone Pygame executable that can be shared and played.

## Modes

MazeWorld supports three generation modes that determine how content is produced:

| Mode | Description | Player Input | Requires |
|------|-------------|--------------|----------|
| **Offline (Static)** | All content pre-generated at build time. NPC dialogue uses scripted dialogue trees with multiple-choice responses. Game varies by seed. | Multiple choice | Nothing (fully self-contained) |
| **Offline (Local)** | World structure is pre-generated, but NPC dialogue and portraits are generated in real-time by locally hosted LLMs and diffusion models. | Free text | Local GPU + model weights |
| **Online (API)** | World structure is pre-generated, but dialogue and images are generated live via API calls to Claude (text) and fal (images). | Free text | Internet + API keys |

## Project Structure

```
MazeWorld/
├── main.py                  # Build tool: generates content and packages the game
├── config.py                # Build and game configuration
├── requirements.txt
├── src/
│   ├── models/              # Game state: maze, player, NPCs, items, dialogue
│   ├── views/               # Pygame rendering: maze, player, NPCs, HUD, dialogue
│   ├── controllers/         # Input handling and game loop
│   ├── utils/               # LLM inference, data loading, display helpers
│   └── generate/            # Pre-generation pipelines for NPC personalities and images
├── data/
│   ├── items/               # Item and entity definitions (JSON)
│   ├── npcs/                # Pre-generated NPC data (generated by main.py)
│   ├── events/              # Event seeds and quest data (generated by main.py)
│   ├── images/              # Generated portraits and assets (generated by main.py)
│   ├── saves/               # Player save files (created at runtime)
│   └── logs/                # Generation and gameplay logs
└── build/                   # Packaged game executables
```

## Setup

```bash
pip install -r requirements.txt
cp .env.example .env   # then edit .env with your values
```

To use API-backed generation, set `LLM_BACKEND=api` and/or `IMAGE_BACKEND=api` in your `.env` and supply the corresponding keys (`ANTHROPIC_API_KEY`, `FAL_KEY`). See `.env.example` for all available variables.

## Requirements

- Python 3.11+
- Pygame 2.6
- PyTorch 2.4+ (for local mode)
- Transformers, Diffusers, Accelerate (for local mode)

See `requirements.txt` for pinned versions.

## Current State

The core game loop is functional: procedural maze generation, player movement with hunger/thirst/health mechanics, item pickup and inventory, three NPC behavior types (static, wandering, aggressive), and NPC dialogue powered by a local Llama 3.2 3B model.

The build pipeline, mode system, screen flow (start/load/config), save/load, quest system, and image generation are in progress. See [ROADMAP.md](ROADMAP.md) for the development plan.

## Known Issues

- NPCs generate a random environment instead of inheriting the maze's environment
- Dialogue scroll can start mid-conversation instead of at the top
