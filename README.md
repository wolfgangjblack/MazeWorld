# MazeWorld

MazeWorld is a 2D overhead RPG where you play as an adventurer navigating procedurally generated mazes. Explore environments, talk to NPCs, collect items, manage survival stats, and find your way out.

World content (mazes, NPCs, quests, events, portraits) is pre-generated by `world_gen.py` and saved to `data/`. The game runtime (`main.py`) loads that data and runs the Pygame loop. If world data is missing when `main.py` starts, it will prompt you to generate it.

## Modes

MazeWorld supports three game modes controlled by the `GAME_MODE` variable in `.env`:

| Mode | `.env` value | Description | Player Input | Requires |
|------|-------------|-------------|--------------|----------|
| **Offline (Static)** | `offline_static` | All content pre-generated at build time. NPC dialogue uses scripted dialogue trees with multiple-choice responses. Game varies by seed. | Multiple choice | Nothing (fully self-contained) |
| **Offline (Local)** | `offline_local` | World structure is pre-generated, but NPC dialogue is generated in real-time by a locally hosted LLM. | Free text | Local GPU + model weights |
| **Online (API)** | `online` | World structure is pre-generated, but NPC dialogue is generated live via API calls to Claude. | Free text | Internet + API keys |

Portraits and world content are always pre-generated by `world_gen.py` regardless of mode. The mode only affects how NPC dialogue is handled at runtime.

## Project Structure

```
MazeWorld/
├── main.py                  # Game runtime: loads world data and runs the Pygame loop
├── world_gen.py             # World generator: pre-generates all content to data/
├── config.py                # Game and generation configuration
├── requirements.txt
├── src/
│   ├── models/              # Game state: maze, player, NPCs, items, events, quests
│   ├── views/               # Pygame rendering: maze, player, NPCs, HUD, dialogue
│   ├── controllers/         # Input handling and game loop
│   ├── prompts/             # LLM prompt templates (Claude and Llama)
│   ├── generate/            # LLM and image generation primitives
│   ├── data/                # Static world data (environment types, names, etc.)
│   └── utils/               # Conversation handling, data loading, display helpers
├── data/
│   ├── items/               # Item definitions (JSON)
│   ├── maze/                # Pre-generated maze layout (generated by world_gen.py)
│   ├── npcs/                # Pre-generated NPC pool (generated by world_gen.py)
│   ├── events/              # Pre-generated events (generated by world_gen.py)
│   ├── quests/              # Pre-generated quests (generated by world_gen.py)
│   └── portraits/           # Generated portrait images (generated by world_gen.py)
└── .env                     # Environment variables (copy from .env.example)
```

## Setup

```bash
pip install -r requirements.txt
cp .env.example .env   # then edit .env with your values
```

### Configuration

Edit `.env` to configure your setup. Key variables:

| Variable | Values | Description |
|----------|--------|-------------|
| `GAME_MODE` | `online`, `offline_local`, `offline_static` | How NPC dialogue works at runtime |
| `LLM_BACKEND` | `local`, `api` | Local Llama or Anthropic API for text generation |
| `IMAGE_BACKEND` | `local`, `api` | Local Flux Schnell or fal.ai API for image generation |
| `ANTHROPIC_API_KEY` | | Required when `LLM_BACKEND=api` |
| `FAL_KEY` | | Required when `IMAGE_BACKEND=api` |
| `hf_write_read` | | HuggingFace token, required when `LLM_BACKEND=local` |

See `.env.example` for the full list.

### Running

```bash
# 1. Generate world content (run once per seed)
python world_gen.py

# 2. Play the game
python main.py
```

## Requirements

- Python 3.11+
- Pygame 2.6
- PyTorch 2.4+ (for local mode)
- Transformers, Diffusers, Accelerate (for local mode)
- sentencepiece, protobuf (for local image generation)

See `requirements.txt` for pinned versions.

## Current State

The core game loop is functional: procedural maze generation, player movement with hunger/thirst/health mechanics, item pickup and inventory, three NPC behavior types (static, wandering, aggressive), NPC dialogue, event encounters (combat and puzzles), and a quest system (fetch, escort, delivery, combat, dialogue-gated). World generation pre-builds all content including LLM-generated NPC personalities, dialogue, events, quests, and portraits.

See [ROADMAP.md](ROADMAP.md) for the development plan.
