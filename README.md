# MazeWorld

MazeWorld is a procedurally generated 2D overhead RPG where players navigate maze environments, engage in turn-based combat, and interact with AI-driven NPCs. All game content — environments, story beats, classes, items, monsters, encounters, portraits, and dialogue — is generated by a multi-phase AI pipeline before the game starts.

---

## Features

### World Generation Pipeline

The generation pipeline runs once before each playthrough and produces a fully populated game world in a single pass. It operates in 11 sequential phases:

| Phase | What it does | LLM calls |
|-------|-------------|-----------|
| 0 | LLM generates a narrative environment sequence (e.g. village → forest → mountain → city → castle) | 1 |
| 1 | Two-pass story generation: overarching faction arc + per-room story beats with named characters | 1 + N |
| 2 | Deterministic maze layout + TileMeta placement (events, NPCs, items, doors) + music/SFX prompts | 2 |
| 3A | Player classes, weapons, spells, utility abilities | 5 |
| 3B–D | Per-room entity databases: items, NPCs (batched), monsters | 3N |
| 4A–B | Batched event/quest generation + dialogue context | ~4N |
| 5 | Structural validation | 0 |
| 6 | Narrative text: synopsis, room intros, game over, victory | N + 3 |
| 7 | Portraits, music tracks (Google Lyria), and SFX (ElevenLabs) — all generated in parallel | 0 (image/audio backends) |
| 8 | Write manifests, stats, and all room data files | 0 |
| 9 | Player guide (optional, `GENERATE_GUIDE=true`) — assembles a strategy-guide-style Markdown + PDF | 0 |

**Key design decisions:**
- Tile positions are determined deterministically in Phase 2 (density-based: `EVENT_DENSITY`, `NPC_DENSITY`, `ITEM_DENSITY` as % of open cells). LLM calls then fill content for those tiles — never the reverse.
- All LLM calls use batching by type to minimize total call count. A 5-room world runs in ~70 LLM calls (down from ~400 in earlier architecture).
- Portraits, music, and SFX are generated concurrently in a single async event loop via `asyncio.gather`.
- Generation stats (tokens, images, audio, cost estimate, wall-clock time) are written to `data/generation_stats.json` at the end of every run.

### Player Classes

- 4 archetypes: warrior, mage, healer, jester — names and flavor text generated to match the starting environment
- 7 stats: STR, DEX, CON, INT, WIS, CHA, LUCK — total budget 95 points, enforced by guardrails
- Classes gain starting abilities/spells and an unlock pool for level-up choices
- Jester presented as a mystery pick (black silhouette) until selected

### Combat

- Turn-based initiative (1d20 + DEX mod), melee vs AC, weapon damage dice
- 5-element magic system: fire › forest › water › fire; light ↔ dark (1.5x/0.5x multipliers)
- Monster abilities: poison (lingering damage), stun, elemental attacks
- Jester's Gamble: LUCK-scaled random effect table
- Use items mid-combat, flee attempt (DEX vs DC), rest action (+5 HP)

### Encounters

Three types placed on maze tiles at generation time (40% combat, 30% puzzle, 30% narrative event):

- **Combat** — monsters drawn from LLM-generated room DB with `hp_range`/`ac_range` rolled at spawn, elemental weaknesses, boss encounters at room exits
- **Puzzle** — correct tool/ability = auto-success; wrong tool = normal stat roll; walk away always available
- **Event** — narrative moment with stat-check choices and meaningful tradeoffs per class

### Quests

- 7 quest types: `combat_event`, `solve_puzzle`, `solve_event`, `fetch_item`, `follower_same`, `follower_next`, `combat_npc`
- `combat_npc` quests make the NPC both a conversation target and a monster entry
- Each quest has `success_dialogue` and `failure_dialogue` templates
- At least 1 story quest guaranteed per room (first quest NPC flagged as story NPC at layout time)
- Cross-room prerequisite chains for multi-step progression

### NPCs

- NPC count scaled by `NPC_DENSITY` (default 2% of open cells per room, ~11–12 per room)
- Types derived from role: `RandomNPC` (quest-givers), `MerchantNPC`, `AggressiveNPC` (`combat_npc`), `StaticNPC` (regular)
- Batch-generated per room: all NPCs for a room in one LLM call with story context + slot metadata
- Each NPC has `max_exchanges` (3–10, set at layout time) — exhaustion line returned when limit reached
- Online mode: personality notes guide live LLM conversation; offline-static: full branching dialogue trees

### Day/Night Cycle

- Action-based (200 actions per full cycle) + optional real-time advancement
- Night reduces fog-of-war radius and enables night-only encounters
- Time-gated events: ~25% of event tiles are day-only or night-only

### Fog of War

- Radius-based visibility with dim outer edge
- Night penalty reduces radius; torch/lantern negates it

### Music & Sound Effects

- **Music** — per-environment tracks generated via Google Lyria 3 (combat, exploration per biome, puzzle, start screen, victory, game over)
- **SFX** — weapon hits, spell casts, ambience per biome, UI sounds generated via ElevenLabs
- Both generated in Phase 7 alongside portraits; controlled by `MUSIC_BACKEND` (`api` enables both, `none` skips both)
- Volume tuneable via `MASTER_VOLUME`, `MUSIC_VOLUME`, `SFX_VOLUME` (0–100)

### Player Guide

- Auto-generated strategy guide in Markdown (+ optional PDF) produced from post-generation data
- Contains: story synopsis, class cards with portraits and stat blocks, per-room dungeon maps (PNG), NPC directory, monster bestiary, event/puzzle guide with choices, quest walkthroughs, and appendices
- No LLM calls — purely assembles existing JSON data and portrait images
- Run standalone: `python -m src.generate.guide_builder` (add `--pdf` for PDF output)
- Or auto-generate during world gen: `GENERATE_GUIDE=true python world_gen.py`

### Save/Load

- Save slots in `data/saves/`, loadable from the start screen

## Three-Mode Architecture

| Mode | `.env` value | Runtime LLM | Runtime Images | NPC Dialogue | Requirements |
|------|-------------|-------------|----------------|--------------|--------------|
| **Online** | `online` | Claude API | fal.ai API | Free-form text input, live LLM responses | API keys, internet |
| **Offline (Local)** | `offline_local` | Local HuggingFace model | Local diffusion | Free-form text input, local model responses | GPU, no API cost |
| **Offline (Static)** | `offline_static` | None | None | Multiple-choice from pre-generated dialogue trees | No GPU, no internet |

`GAME_MODE` is a **generation-time setting** — the pipeline bakes different data depending on the mode (e.g., `offline_static` generates full branching dialogue trees per NPC, while `online` generates personality context for live conversations). You must set it before generating and regenerate if you change it.

### Switching modes

1. Set `GAME_MODE` in `.env` to the desired mode
2. Pair it with the right backends:

```env
# Online — API backends, requires ANTHROPIC_API_KEY and FAL_KEY
GAME_MODE=online
LLM_BACKEND=api
IMAGE_BACKEND=api

# Offline (Local) — local models, requires GPU + HuggingFace token
GAME_MODE=offline_local
LLM_BACKEND=local
IMAGE_BACKEND=local

# Offline (Static) — backends only matter during generation, not at runtime
GAME_MODE=offline_static
LLM_BACKEND=api        # or local — only used during generation
IMAGE_BACKEND=api      # or local — only used during generation
```

3. Delete existing world data and regenerate:

```bash
rm -rf data/
python main.py --dev
```

## Setup

```bash
pip install -r requirements.txt
cp .env.example .env   # edit with your values
```

Key `.env` settings:

```env
GAME_MODE=online              # online | offline_local | offline_static
LLM_BACKEND=api               # api | local
IMAGE_BACKEND=api             # api | local
ANTHROPIC_API_KEY=sk-...
FAL_KEY=...

# Music & SFX (optional — set to "none" to disable)
MUSIC_BACKEND=api             # none | api (enables both Lyria music + ElevenLabs SFX)
GOOGLE_API_KEY=...
ELEVENLABS_API_KEY=...

# Player guide (auto-generate after world gen)
GENERATE_GUIDE=true           # true | false
```

## Running

```bash
# Generate world content, then launch game
python main.py --dev

# Skip generation, use existing data/
python main.py --dev --skip-gen

# Run generation only (no game window)
python world_gen.py

# Generate world + player guide in one pass
GENERATE_GUIDE=true python world_gen.py

# Build player guide from existing data (no world gen)
python -m src.generate.guide_builder
python -m src.generate.guide_builder --pdf    # include PDF output
```

After generation completes, the terminal prints a stats summary:

```
=== Generation Stats ===
  Time: 39m 16s
  LLM: 54 calls, 174,042 tokens (84,790 in / 89,252 out) [api]
  Images: 574/574 generated [api]
  Music: 8/8 tracks [api]
  SFX: 15/15 effects [elevenlabs]
  Estimated cost: $1.67 (LLM: $1.59, Images: $0.07, Audio: $0.01)
```

## Project Structure

```
MazeWorld/
├── main.py                   # Entry point (game loop)
├── world_gen.py              # Entry point (generation only)
├── config.py                 # All tuneable parameters
│
├── src/
│   ├── controllers/          # Input, screen state machine, game, combat
│   ├── generate/
│   │   ├── pipeline.py       # Main orchestrator: generate_world()
│   │   ├── pipeline_utils.py # Pure helpers (items, quests, loot)
│   │   ├── generation_stats.py # Token/image/audio/cost/time tracking
│   │   ├── guide_builder.py  # Post-generation player guide (Markdown + PDF)
│   │   ├── backends/         # LLM (api/local) + image (api/local) backends
│   │   ├── generators/
│   │   │   └── llm_primitives.py  # All LLM call wrappers
│   │   ├── class_gen.py      # Class generation + stat guardrail enforcement
│   │   ├── image_client.py   # Parallel portrait generation
│   │   ├── music_client.py   # Music track generation (Google Lyria)
│   │   ├── sfx_client.py     # Sound effect generation (ElevenLabs)
│   │   ├── summary_agent.py  # Narrative text generation
│   │   ├── world_editor.py   # Cross-validation and coherence checks
│   │   ├── checker.py        # Pre-validation content checks
│   │   └── validator.py      # Post-validation rules
│   ├── models/               # Data models: player, maze, monsters, items, quests, etc.
│   ├── prompts/              # LLM prompt sets (Claude + Llama variants)
│   ├── systems/              # Game systems: survival, fog-of-war, day/night, saves,
│   │                         #   music controller, SFX controller
│   ├── views/                # Pygame rendering for all screens
│   └── registry.py           # Item registry
│
├── data/                     # Generated world content (gitignored except stubs)
│   ├── rooms/room_N/         # Per-room: maze, npcs, events, quests, items
│   ├── classes/              # Player class definitions
│   ├── story/                # Overarching story + room beats
│   ├── portraits/            # Generated images by entity type
│   ├── music/                # Generated music tracks (.mp3)
│   ├── sfx/                  # Generated sound effects (.mp3)
│   ├── guide/                # Player guide output (Markdown + PDF)
│   ├── saves/                # Player save slots
│   └── generation_stats.json # Generation metadata (tokens, costs, timing)
│
└── tests/                    # pytest suite
```

## Requirements

- Python 3.11+
- Pygame 2.6, Pydantic 2.9+, tqdm, python-dotenv
- Anthropic SDK (online mode)
- fal-client (API image generation)
- google-genai (music generation via Lyria)
- elevenlabs (SFX generation)
- Pillow (map rendering for player guide)
- markdown, weasyprint (PDF guide generation — optional)
- PyTorch 2.4+, Transformers, Diffusers, Accelerate (local mode only)

See `requirements.txt` for pinned versions.
